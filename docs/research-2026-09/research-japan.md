# 日本市場：標的型メール訓練・セキュリティ意識向上サービス調査（2025-2026）

## サービス別要約

### LRM「セキュリオ」
- クラウド型セキュリティ運用プラットフォームの一機能として標的型攻撃メール訓練を提供。1ユーザー月額150円（税抜）からの価格帯情報あり（詳細プランは要問合せ）[1][7]。
- Eラーニング教材90種類以上、開封者への自動eラーニング配信機能を追加（プレスリリースで発表）[6]。
- Outlook/Gmail双方に対応した「フィッシング報告」アドインを提供し、Microsoft Graph API連携で不審メール報告→訓練メール自動判定まで自動化[15]。
- 訓練と教育の結果を1画面で管理し、開封率ゼロを目指すセルフサービス型運用[13]。
- GSXが自社サービスとしてセキュリオを取次販売しており、代理店経由の提供も存在[26]。
- SCORM対応・IPA/経産省ガイドライン準拠の明記は検索範囲内では確認できず、未確認。

### GMOサイバーセキュリティ byイエラエ
- ホワイトハッカー由来の脆弱性診断が主力事業。2026年1月に中小企業向け低価格プラン「ネットde診断 Lite」（月額4,280円）を発表したが、これは脆弱性診断であり標的型メール訓練の専用サービスとしての詳細な価格・機能は検索範囲内で確認できず未確認[2]。

### NTTデータ/NTTグループ（NTT東日本・NTT西日本）
- NTT東日本は「標的型攻撃メール訓練」を提供してきたが、**2025年12月17日新規申込終了、2026年6月30日サービス提供終了が発表**（2025-2026年の大きな市場変化）[22]。
- NTT西日本は「AQStage 標的型メール攻撃 予防訓練サービス」を継続提供、部署・役職別の文面カスタマイズ、オプション組み合わせ型の料金体系[3]。
- NTTビジネスソリューションズが同サービスメニューを提供[3]。

### ラック「標的型攻撃メール訓練T3」
- 「T3」：総配信数100件で210,000円（税抜）、配信総数に応じ変動。上位版「T3 Plus」は880,000円（税抜）[4]。
- 「T3 with セキュリティ教育」は1ユーザー月額50円から、契約期間中は訓練・eラーニングを回数無制限で利用可能[4]。
- コンサルタントによる全部委託型の運用が中心（自社運用のSaaS型ウェビナーも展開）[19]。
- テンプレート種類は比較記事上で最多水準（54種）との記載あり[21]。

### KDDI（KDDIデジタルセキュリティ / KIS）
- 「KIS MailMon」は年額36,000円から。「送信数プラン」「送信数無制限プラン」の2種類、送信数とユニークアドレス数で価格決定。導入800社超（金融機関100社以上含む）[8]。
- KDDIデジタルセキュリティはラックのT3配信基盤を使った標的型攻撃メール訓練サービスも提供[8]。

### 日立ソリューションズ/日立システムズ
- 日立ソリューションズは標的型メール訓練サービスを提供、氏名・部署名を挿入したメール文面や対象者ごとの内容変更などカスタマイズ対応[9]。
- 日立システムズは「SHIELD 標的型攻撃メール訓練サービス」を展開（全部委託型）[21]。
- 日立ソリューションズはProofpoint製品を「ZenGuide」ブランドで再販（PSATの日本語ブランド展開）[12]。

### SB C&S「AironWorks」
- 2025年1月にAironWorks社とディストリビューター契約を締結し取り扱い開始。イスラエル発（CEOは日本人）のAI活用型標的型メール訓練サービス[10][23]。
- AIとアナリストがプレスリリースや業界ニュース等のリアルタイム情報を活用し、パーソナライズされた訓練メールを自動生成するのが最大の特徴[21]。
- SMS・SNSを含む多様な攻撃手法に対応、教育コンテンツからレポートまで自動化。料金は要問合せで非公開[10]。

### IIJ（インターネットイニシアティブ）
- 「IIJセキュリティ診断ソリューション」内で標的型メール攻撃訓練を提供。標準メニューから文面・送信数・パターンを選択でき、個別カスタマイズにも対応[11]。
- IIJアメリカ法人はKnowBe4を用いた訓練の実践例をブログで紹介しており、グループ内でKnowBe4の知見が共有されている（日本本体がKnowBe4正規代理店かは未確認）[11]。

### マクニカ（Proofpoint 一次代理店）
- マクニカは2020年に米Proofpointと一次代理店契約を締結、内部脅威対策・次世代型メールセキュリティ・PSAT（Security Awareness Training）を展開[17]。
- 2025年のProofpointパートナーアワードで「リセラー＆インテグレーター・オブ・ザ・イヤー賞」を受賞[17]。
- 検索範囲内では、マクニカがKnowBe4の国内代理店であることは確認できず（KnowBe4の主要代理店はSCSK・パナソニック）、当初の想定は未確認。

### Proofpoint Japan（Security Awareness Training / PSAT）
- 診断・教育・強化・測定の4フローで構成されるSaaS型トレーニング。脅威インテリジェンスと連動したパーソナライズ配信[12]。
- 30以上の言語、30種類超のトレーニングモジュール（1件5-15分）に対応。クリックしたユーザーへの自動追加教育機能あり[12]。
- 日本では日立ソリューションズが「ZenGuide」、ユニアデックス、テクマトリックスなど複数のSIerが再販[12]。
- 料金はオープンプライス（要問合せ）[19]。

### グローバルセキュリティエキスパート（GSX）「トラップメール」
- 累計導入企業11,000社以上で国内シェアNo.1を標榜。スタンダード内容（訓練メール1回送信＋開封状況リスト＋報告書）は55万円から[14]。
- 開封時コンテンツにランサムウェア画面を用いた「身代金要求ボタン」演出など臨場感のある教育コンテンツを提供[24]。
- 標的型攻撃を熟知したコンサルタントによる助言付きで、比較的低コスト・約4週間で実施可能な短納期プランもあり[14]。
- 自社の「トラップメール」に加え、LRM「セキュリオ」を取次販売する形でAI時代のセキュリティ教育ニーズにも対応[26]。
- SCORM対応・報告ボタン機能の詳細は検索範囲内で確認できず未確認。

### ヒューマンサイエンス
- 主力事業はマニュアル制作・翻訳・eラーニング（2,600件超の実績）。標的型メール訓練に特化したサービスの詳細情報は検索範囲内で確認できず、専業ベンダーではない可能性が高い（未確認）[16]。

### MudFix（JSecurity開発、キヤノンITソリューションズ取扱）
- JSecurity（株式会社ジェイ・セキュリティ）が開発するクラウド完結型サービス。初期費用・サーバー構築不要で即日利用開始可能[18]。
- 添付ファイル型・フィッシング誘導型などテンプレートが充実し、送信数・送信頻度を気にせず無制限訓練が可能なプランを用意[18]。
- 料金は年間2,400～3,840円/ユーザー程度（比較記事に基づく）[20]。
- 2025年3月24日よりキヤノンITソリューションズが自社の総合ITインフラサービス「SOLTAGE」のセキュリティラインアップとして取り扱い開始（新たな販売チャネル拡大）[18]。

### Phish Insight（Trend Micro）
- 実際のフィッシング詐欺から抽出したテンプレートを用いる無料のフィッシングシミュレーションサービスとして提供されてきたが、**2024年12月末をもって新規登録を終了し、後継の「Trend Vision One - Security Awareness」へ機能移行中**（2025-2026年にかけての大きな製品移行）[5]。

### 新規参入・注目トレンド（2025-2026）
- トビラシステムズ「サギトレ」：2025年10月29日リリース。詐欺メール・SMS訓練（スミッシング対応）にAI分析を組み合わせ、年間約50億件の迷惑情報判定データベースを活用し個人・部門別リスク傾向を可視化[25]。
- Selphish（神戸デジタル・ラボ）、CYAS（CYLLENGE）等、教育コンテンツ一体型の新興SaaSが比較記事で複数掲載され、月額課金・少額から開始できるプランが中小企業向けに拡大[19][20]。
- QRコードを使った「クイッシング」訓練、偽の操作手順を装う「ClickFix」型詐欺への対応テンプレートなど、攻撃手法の多様化が2025-2026年のテンプレート追加トレンドとして各社比較記事に記載[21]。
- 「Sakura」という名称の専業ミッションクリティカル系SaaSは検索範囲内で特定できず、未確認。

## 国内市場で差別化になっている機能

- AI生成シナリオ：企業ニュースや業界動向を取り込み訓練メール文面を自動生成（AironWorks、トビラシステムズ サギトレ）[10][25]。
- QRコード「クイッシング」・偽操作手順「ClickFix」型など、メール以外の攻撃経路への対応拡大[21]。
- SMS/スミッシング訓練の統合（トビラシステムズが2025年10月に新規参入）[25]。
- Outlook/Gmail向け不審メール報告アドインとの連動による自動判定・対応時間短縮（セキュリオ）[15]。
- 開封時コンテンツにランサムウェア型「身代金要求ボタン」演出を組み込む臨場感重視の教育設計（GSX）[24]。
- 訓練とeラーニングの回数無制限・月額数十円/人という低価格セルフサービスプランの拡大（ラックT3 with教育、MudFix）[4][18]。
- 大手SIerによる海外製品（KnowBe4、Proofpoint）の日本語ローカライズ・代理店展開（SCSK×KnowBe4、マクニカ×Proofpoint、日立ソリューションズZenGuide）[12][17]。
- 医療機関向けにCSIRT主導の地域単位訓練や厚労省チェックリスト対応が2025年に強化[27]。
- 大手通信キャリア系（NTT、KDDI、IIJ、SB C&S）が複数ブランドで並行提供し、既存回線契約者への抱き合わせ販売がしやすい構造。
- 老舗サービス（NTT東日本）が2026年に撤退する一方、AI活用の新興SaaS（トビラ、AironWorks）が2025年に相次いで参入する世代交代が進行中[10][22][25]。
