### 不審メールの見分け方（aw-mail）

**aw-mail-01**（場面、難易度 2、狙う正答率 72%）

取引先の担当者の名前で、請求書を添付したメールが届いた。本物かを見分けるため、まず確かめることはどれか。

1. 表示名が担当者の名前と一致しているか
2. 表示名の横にある実際のアドレスのドメイン（正解）
3. 本文に自分の名前と社名が正しくあるか
4. 添付を開き、請求内容が取引と合うか

ポイント：差出人は表示名ではなく実際のアドレスで確かめ、不審なら以前から知る連絡先で問い合わせる。

**aw-mail-02**（最も適切、難易度 3、狙う正答率 60%）

取引先のメールの添付ファイルを開くと、「内容の表示には機能の有効化が必要」と表示された。最も適切な対応はどれか。

1. 知っている取引先なので、有効にして中身を見る
2. ウイルス対策ソフトで検査し、問題なければ有効にする
3. メールに返信し、有効にしてよいかを尋ねる
4. 有効にせず閉じ、情報システム担当に相談する（正解）

ポイント：添付を開いて機能の有効化を求められたら、有効にせずに閉じて相談する。

**aw-mail-03**（誤り、難易度 2、狙う正答率 70%）

社内の部署や社内システムを名乗るメールについての説明として、誤っているものはどれか。

1. 社内の部署を名乗るメールが、社外から届くことがある
2. 通知のリンクではなく、普段の入口から社内システムに入る
3. 自分の名前や部署名が正しければ、社内からと判断できる（正解）
4. パスワード期限切れの通知は、社内の案内方法と照らし合わせる

ポイント：社内を名乗るメールでも名前の正しさを根拠にせず、リンクではなく普段の入口から確かめる。

### フィッシングと偽サイト（aw-phishing）

**aw-phishing-01**（場面、難易度 3、狙う正答率 60%）

業務用スマホに、取引銀行を名乗り「取引を制限した。解除はこちら」とリンク付きのSMSが届いた。最も適切な対応はどれか。

1. リンクは開かず、いつもの公式アプリで口座を確かめる（正解）
2. リンクのアドレスに銀行名が入っているかを見て開く
3. SMSに書かれた問い合わせ番号へ電話して確かめる
4. 取引の制限を早く解くため、リンクから手続きする

ポイント：SMSやメールのリンクからは入力せず、公式アプリやブックマークから開き直す。

**aw-phishing-02**（場面、難易度 2、狙う正答率 72%）

会議室の壁に、総務部名義で再登録を求めるQRコードの紙があり、読み取るとログイン画面が開いた。どうするか。

1. 画面がいつもと同じ見た目なら、IDを入力する
2. 総務部の名前があるので、指示どおり再登録する
3. 同僚が読み取らないよう、紙をはがして捨てる
4. 入力せずに閉じ、掲示のことを窓口に知らせる（正解）

ポイント：QRコードから開いた画面ではIDやパスワードを入力せず、普段の入口から開き直す。

**aw-phishing-03**（最初の行動、難易度 2、狙う正答率 74%）

メールのリンクから開いたページに業務用のIDとパスワードを入力した後、偽サイトだと気づいた。最初に行うことはどれか。

1. パスワードを変えて、被害がなければ報告しない
2. 情報システム担当に、入力した内容と時刻を報告する（正解）
3. ブラウザの閲覧履歴を消して、偽サイトの記録を消す
4. 不審なログイン通知が届くまで、様子を見る

ポイント：偽サイトに入力したと気づいたら、入力した内容と時刻をすぐに報告する。

### パスワードと多要素認証（aw-auth）

**aw-auth-01**（最も適切、難易度 2、狙う正答率 75%）

自分が何も操作していないのに、スマホに多要素認証の承認通知が届いた。最も適切な対応はどれか。

1. 誤操作かもしれないので、一度だけ承認して様子を見る
2. 拒否したので問題は解決したと考え、そのままにする
3. 承認せずに拒否し、情報システム担当へ報告する（正解）
4. 通知が止まるまで、スマホの電源を切っておく

ポイント：身に覚えのない承認通知は拒否し、パスワードが漏れた兆候として報告する。

**aw-auth-02**（場面、難易度 3、狙う正答率 58%）

私用の通販サイトから情報漏えいの通知が届いた。同じパスワードを業務のクラウドでも使っている。最も適切な対応はどれか。

1. 業務側も別のパスワードに変え、担当者に伝える（正解）
2. 漏えいした通販サイトのパスワードだけを変える
3. 業務側はパスワードの末尾の数字だけを変える
4. 業務側は多要素認証があるので、そのままにする

ポイント：業務と私用でパスワードを使い回さず、漏えいを知ったら業務側も変えて担当者に伝える。

**aw-auth-03**（場面、難易度 1、狙う正答率 84%）

社内のIT担当を名乗る人から電話で「設定確認のため、今スマホに届いた6桁のコードを読み上げて」と言われた。どうするか。

1. 相手の名前と内線番号を聞いてから、コードを伝える
2. 急ぎだと言われたので、その場でコードを読み上げる
3. コードは数分で無効になるので、伝えても問題ない
4. コードは伝えずに電話を切り、社内の窓口に知らせる（正解）

ポイント：確認コードや承認は、相手が誰を名乗っても伝えず、求められたことを報告する。

### ランサムウェアとマルウェアの兆候（aw-malware）

**aw-malware-01**（最も適切、難易度 1、狙う正答率 86%）

ランサムウェアの感染を疑い、すぐに報告すべき兆候として最も適切なものはどれか。

1. ソフトの更新通知が、作業中に何度か表示された
2. 共有フォルダのファイル名が、見慣れない拡張子に変わった（正解）
3. 迷惑メールのフォルダに、広告のメールがたまっていた
4. パソコンの起動が、いつもより数秒遅かった

ポイント：ファイルが開けない、拡張子が変わったと気づいたら、様子を見ずにすぐ報告する。

**aw-malware-02**（場面、難易度 3、狙う正答率 58%）

作業中のPCに突然、「ファイルを暗号化した。復元したければ支払え」という画面が表示された。まず行うことはどれか。

1. 外付けのバックアップをつなぎ、すぐ復元を試す
2. ウイルス対策ソフトで全体を検査し、結果を待つ
3. ネットワークから切り離し、すぐに報告する（正解）
4. 画面の連絡先に、復元の方法を問い合わせる

ポイント：脅迫の画面が出たら、ネットワークから切り離し、電源は入れたまま報告する。

**aw-malware-03**（最初の行動、難易度 2、狙う正答率 70%）

メールの添付ファイルを開いた後、PCの動作が急に重くなり、見知らぬ窓が一瞬表示された。最初に行うことはどれか。

1. 電源は入れたまま、ネットワークから切り離して報告する（正解）
2. 再起動して、動作が元に戻るかを確かめる
3. 開いた添付ファイルとメールを削除しておく
4. 同じことがもう一度起きたら、報告する

ポイント：異常に気づいたら、再起動や削除をせず、ネットワークから切り離して報告する。

### 送金依頼となりすまし（aw-bec）

**aw-bec-01**（場面、難易度 2、狙う正答率 70%）

取引先から「振込口座を変更した」とメールが届いた。支払いの前にまず行うことはどれか。

1. 以前から使っている連絡先で取引先の担当者に確認する（正解）
2. メールの署名にある電話番号へ電話して確認する
3. 期日に遅れないよう新しい口座へ振り込み、後で報告する
4. メールに返信して、変更が本当かを問い合わせる

ポイント：口座や支払先の変更は、メール以外の、前から知っている連絡先で必ず確かめる。

**aw-bec-02**（場面、難易度 2、狙う正答率 70%）

社長の名前で「チャットのグループを作り、招待のQRコードを返信して。社内には内密に」とメールが届いた。どうするか。

1. 社長あてに返信し、本当に社長本人かを尋ねる
2. メールには返信せず、社内の窓口に報告する（正解）
3. グループだけ作り、送金の指示が来たら確かめる
4. 内密にと書かれているので、誰にも相談せず従う

ポイント：社長を名乗るメールでグループ作りやQRコードの返信を求められたら、応じずに報告する。

**aw-bec-03**（最も適切、難易度 3、狙う正答率 58%）

オンライン会議で、映像も声も上司そっくりの相手から、至急の送金を指示された。最も適切な対応はどれか。

1. 映像の顔と声が本人と同じか、よく見て判断する
2. その場で、上司しか知らないことを質問する
3. 指示どおりに送金し、会議を録画して証拠を残す
4. 会議を終えてから、登録済みの番号で上司に確かめる（正解）

ポイント：声や映像で上司や取引先を名乗る送金の依頼は、登録済みの連絡先へかけ直して確かめる。

### 生成AIの使い方（aw-genai）

**aw-genai-01**（場面、難易度 3、狙う正答率 60%）

自宅で、社外秘の会議メモを私用スマホの無料のAIサービスで要約しようと考えた。最も適切な対応はどれか。

1. 固有名を伏せれば、私用のAIに入力してもよい
2. 学習に使わない設定にすれば、私用のAIでもよい
3. 会社が許可したAIを、規程の範囲で会社の端末で使う（正解）
4. 急ぎなので、今回だけ私用のAIに貼り付ける

ポイント：業務データは、会社が許可したAIサービスにだけ、規程の範囲で入力する。

**aw-genai-02**（最も適切、難易度 2、狙う正答率 72%）

生成AIに作らせた提案書の下書きに、統計の数値と出典の資料名が書かれていた。最も適切な扱いはどれか。

1. 出典の資料名が書かれているので、そのまま使う
2. 数値と出典を、元の資料で確かめてから使う（正解）
3. 同じAIに正しいかを尋ね、正しいと答えれば使う
4. 数値を丸めて書けば、誤っていても影響は小さい

ポイント：生成AIの出力にある数値、固有名、出典は、元の資料で確かめてから使う。

**aw-genai-03**（誤り、難易度 2、狙う正答率 70%）

生成AIサービスの業務での利用についての説明として、誤っているものはどれか。

1. 許可されたサービスでも、入力できる情報の範囲は規程に従う
2. AIの回答は、もっともらしい誤りを含むことがある
3. 攻撃者もAIで、自然な日本語の詐欺メールを作れる
4. 入力した内容は、会話を削除すればどこにも残らない（正解）

ポイント：生成AIに入力した内容は取り消せないと考え、入力してよい情報かを入力の前に確かめる。

### 個人情報と機密情報の取扱い（aw-data）

**aw-data-01**（最も適切、難易度 3、狙う正答率 60%）

顧客の名簿を添付して、社外の相手にメールを送る。送信前の確認として最も適切なものはどれか。

1. 宛先の名前とアドレス、添付の中身を開いて確かめる（正解）
2. 宛先を、アドレス帳の候補から選んだことを確かめる
3. 添付したファイルの名前が正しいかを確かめる
4. 送った後に、相手に届いたかを電話で確かめる

ポイント：社外へ送る前に、宛先は名前とアドレスで、添付は中身を開いて確かめる。

**aw-data-02**（場面、難易度 2、狙う正答率 72%）

「社外秘」の区分が付いた設計資料を、週末に自宅で見直したい。最も適切な対応はどれか。

1. 私用のメールアドレスへ送り、自宅のPCで開く
2. 印刷して持ち帰り、見終えたら家庭ごみで捨てる
3. 規程の手続きを取り、会社が認めた方法で持ち出す（正解）
4. 会社のPCで持ち帰るなら、手続きはいらない

ポイント：機密区分の付いた資料は、規程で決めた手続きと方法でだけ持ち出す。

**aw-data-03**（最も適切、難易度 2、狙う正答率 72%）

会議の資料を、同僚が私物のUSBメモリに入れて渡してくれた。業務PCで開く前の対応として最も適切なものはどれか。

1. 同僚の私物なので安全と考え、そのままつなぐ
2. 業務PCにつながず、会社が認めた方法で送り直してもらう（正解）
3. ウイルス対策ソフトで検査してから、業務PCで開く
4. 開いた後、資料を業務PCから削除しておく

ポイント：私物の記憶媒体は業務PCにつながず、会社が認めた方法でデータを受け渡す。

**aw-report-01**（場面、難易度 2、狙う正答率 72%）

**aw-report-03**（場面、難易度 3、狙う正答率 60%）

2. 自分のパスワードを変え、報告はせずに済ませる

4. 取引先にそのメールを削除してもらえば済む

ポイント：身に覚えのない送信を指摘されたら、自分で片付けずにすぐ報告する。

### 偽の警告と電話詐欺（aw-scam）

**aw-scam-01**（場面、難易度 1、狙う正答率 85%）

Webで調べものをしていると、警告音とともに「ウイルスに感染」という画面と電話番号が表示された。最も適切な対応はどれか。

1. 表示された番号に電話して、対処の方法を聞く
2. 電話はかけず、ブラウザを閉じて窓口に知らせる（正解）
3. 画面のボタンを押して、感染の状況を確かめる
4. 警告音が止まるまで、閉じずにそのまま待つ

ポイント：偽のウイルス警告の電話番号にはかけず、ブラウザを閉じて報告する。

**aw-scam-02**（場面、難易度 3、狙う正答率 58%）

取引銀行を名乗る電話で「法人口座の手続きの案内を送るので、メールアドレスを教えて」と言われた。どう対応するか。

1. 担当者の名前と支店名を聞いてから、アドレスを伝える
2. 相手が口座番号を知っていれば、アドレスを伝える
3. 手続きが遅れないよう、その場でアドレスを伝える
4. いったん切り、銀行の代表番号にかけ直して確かめる（正解）

ポイント：銀行や取引先を名乗る電話で情報を求められたら、いったん切り、自分で調べた番号にかけ直す。

**aw-scam-03**（最も適切、難易度 1、狙う正答率 82%）

偽の警告画面の番号に電話し、言われるままに遠隔操作のソフトを入れてしまった。最も適切な対応はどれか。

1. ネットワークから切り離し、すぐ窓口に報告する（正解）
2. 入れたソフトを、自分でアンインストールする
3. もう一度電話をかけ、操作をやめるよう頼む
4. 叱られないよう、何もなかったことにする

ポイント：電話してしまった、ソフトを入れてしまった時は、隠さずすぐに報告する。

### テレワークと社外での業務、SNS（aw-remote）

**aw-remote-01**（最初の行動、難易度 1、狙う正答率 85%）

出張の帰りの電車に、業務用のノートPCを置き忘れたと気づいた。最初に行うことはどれか。

2. 暗号化されているので、報告はしなくてよい
3. すぐに会社の窓口へ紛失を報告する（正解）

**aw-remote-02**（場面、難易度 2、狙う正答率 70%）
