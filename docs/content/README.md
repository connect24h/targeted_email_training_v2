## 3. 制作の手順

コンテンツは次の3つの skill で作る。

| skill | 場所 | 役割 |
|---|---|---|
| zukai-book | `~/.claude/skills/zukai-book/`（汎用） | 見開きの図解本の原稿、校正、画像（Codex の画像生成か SVG）、A5 の組版、PowerPoint（lite）の出力、視覚検査、元資料との類似度検査 |
| tet2-security-zukai | `/root/tet2/.claude/skills/tet2-security-zukai/` | tet2 の教材の雛形（従業員向け、管理者向け）、用語集、構成の型、画像の型、文章の独自性の検査、tet2 への取込の確認 |
| tet2-awareness-quiz | `/root/tet2/.claude/skills/tet2-awareness-quiz/` | 小問の書き方、検証、取込用 Excel、場面の画像、独自性と類似度の検査、合成 DB への取込の確認 |

`/root/tet2/.claude/` は `.gitignore` で除外されているため、tet2 専用の2つの skill は git で管理されていない。

## 4. 守っていること

- 他社の教材の文章、設問、画像を流用しない。分析して得た型だけを使い、文章は文字列の一致、画像は特徴点の照合で、他社の教材と比べて確かめる。
- 事実の記述には出典を残す。題材選定の未確認事項に当たる数値や項番は、資料で確かめるまで書かない。
- 訓練メールを見破る手掛かり（訓練メールの件名、差出人、テンプレート）を教材と小問に書かない。
- 初動の手順（端末の電源、ネットワークからの切り離し）は顧客ごとに異なるので、「社内の手順があればそれに従う」を先に置く。

## 5. 機能との関係

- 今の tet2 の受講画面は、教材を文字のスライドとして表示し、画像を表示しない。設問にも画像を付けられない。そのため、PowerPoint の文字だけが受講者に届く。
- [08 機能拡張の検討](../spec/08-feature-expansion-review.md) の G16（教材のページ画像表示）と G17（設問の画像と選択肢ごとの解説）が入れば、A5 の図解 PDF と場面の画像を受講者に届けられる。
- 小問の正答率の目標（60〜85%）を運用で確かめる画面は、08 の G22（設問の品質分析）で検討している。
- 分野別の理解度は、[07 アップデート設計書](../spec/07-seculio-benchmark-update-design.md) の U5 で設計している。
