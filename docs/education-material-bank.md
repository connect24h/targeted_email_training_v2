## 画面と権限

管理画面の「教材バンク」で操作する。

| 操作 | viewer | operator | superadmin |
|---|---:|---:|---:|
| 教材と設問の閲覧・試行 | 可 | 可 | 可 |
| 全設問・回答付き一覧 | 可 | 可 | 可 |
| Excelテンプレート取得・全設問出力 | 可 | 可 | 可 |
| PowerPoint取込・教材保存 | 不可 | 可 | 可 |
| Excelから設問追加 | 不可 | 可 | 可 |
| 自組織の教材・設問編集 | 不可 | 可 | 可 |
| 共有教材・共有カテゴリの直接編集 | 不可 | 不可 | 可 |

operatorが共有カテゴリへ設問を追加する場合は、先にカテゴリを自組織へコピーする。
一覧、出力、取込では自組織と共有データだけを扱い、他組織のデータは含めない。

## PowerPointからスライド教材を作る

1. 「教材バンク」の「PowerPoint読込」を選ぶ。
2. `.pptx`ファイルを選択する。
3. 取り込まれたタイトルと本文を編集画面で確認する。
4. 必要に応じて修正し、教材として保存する。
5. 教材一覧の「教材を試行」で表示を確認する。

取込対象は各スライドのタイトルと本文の文字列である。
画像、動画、アニメーション、レイアウトは取り込まない。
タイトル枠がない場合は最初の本文をタイトルとして扱い、文字列がない場合はスライド番号を補う。

PowerPointの制限は次のとおりである。

- 形式: `.pptx`
- ファイルサイズ: 5 MB以内
- スライド数: 1枚から50枚
- 1枚のタイトル: 200文字以内
- 1枚の本文: 10,000文字以内

取込は教材を即時保存しない。
内容確認後に保存操作を行った時点で教材へ反映する。

## 確認テストを一覧・プレビューする

カテゴリタブの「全カテゴリ」を選ぶと、閲覧可能な全設問を一覧できる。
各設問の「試行」では回答を選び、その場で正誤、正答、解説を確認できる。
試行結果は受講履歴や採点結果へ保存しない。

「回答付き一覧」では、全カテゴリの設問、選択肢、正答、解説、種別、難易度を1画面に表示する。
この表示も受講履歴や採点結果を変更しない。

## 設問をExcelへ出力する

「Excel出力」は、自組織と共有の全設問を`.xlsx`で出力する。
現在選択しているカテゴリだけには限定せず、無効な設問も含める。
他組織の設問は含めない。

出力列は次のとおりである。

| 列 | 内容 |
|---|---|
| カテゴリ名 | 表示用のカテゴリ名 |
| カテゴリスラッグ | カテゴリを識別する文字列 |
| 設問文 | 確認テストの設問 |
| 種別 | `single_choice`、`true_false`、`multiple_choice` |
| 選択肢（改行区切り） | 1セル内に改行で記載した選択肢 |
| 正答番号（1始まり） | 単一正答は`1`、複数正答は`1,3`のように記載 |
| 難易度 | 1から3 |
| 解説 | 回答後に表示する説明 |
| 有効 | `1`が有効、`0`が無効 |

## Excelから設問を追加する

1. 「Excelテンプレート」をダウンロードする。
2. 「設問」シートへ1行につき1設問を入力する。
3. 列名を変更せずに`.xlsx`で保存する。
4. 「Excel読込」からファイルを選択する。
5. 追加件数と教材バンクの一覧を確認する。

テンプレートには「設問」「カテゴリ一覧」「入力方法」の3シートがある。
取込処理が読むのは先頭のワークシートであるため、「設問」シートを先頭に保つ。
カテゴリスラッグは「カテゴリ一覧」で「追加可能」と表示される値を使用する。

取込列は次のとおりである。

| 列 | 必須 | 入力規則 |
|---|---:|---|
| カテゴリスラッグ | 必須 | 自組織の有効なカテゴリを指定する。共有カテゴリはsuperadminだけが直接指定できる |
| 設問文 | 必須 | 1文字から200文字 |
| 種別 | 必須 | `single_choice`、`true_false`、`multiple_choice`。日本語の「単一選択」「正誤」「複数選択」も可 |
| 選択肢（改行区切り） | 必須 | 2件から20件。各選択肢は1,000文字以内 |
| 正答番号（1始まり） | 必須 | 選択肢の番号を指定する。複数選択はカンマ区切り |
| 難易度 | 必須 | 1から3 |
| 解説 | 任意 | 5,000文字以内 |
| 有効 | 任意 | `1`または`0`。空欄は`1` |

Excelの制限は次のとおりである。

- 形式: `.xlsx`
- ファイルサイズ: 5 MB以内
- 行数: ヘッダーを含め1,001行以内
- 追加可能数: 1ファイルにつき最大1,000設問

全行を検証してからtransactionで追加する。
不正な行が1行でもあれば、設問を1件も追加せず、該当行と理由を表示する。

## セキュリティ上の扱い

OfficeファイルはZIP内のXML文字列だけを読み取る。
マクロ、数式、画像、外部リンク、外部relationshipは実行しない。
ZIP内の項目数、展開後サイズ、パスを検証し、不正なarchiveと過大なarchiveを拒否する。

取込APIはoperator以上の認証とCSRF tokenを必須とする。
共有データの変更権限とtenant境界はAPI側でも検証する。
画面表示ではHTML escapeまたは`textContent`を使用する。
